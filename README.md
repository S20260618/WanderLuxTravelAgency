# WanderLux Travel Agency Website

This project is a minimal responsive travel agency website built with modern HTML5 and CSS3 with no external framework.

The site includes a trip cost calculator, online appointment booking, and a contact form with input validation.

## Project Structure

```text
├── index.html                  # Home page with hero slider and package highlights
├── services.html               # Destinations and travel services
├── calculator.html             # Interactive trip cost calculator
├── appointment.html            # Consultation booking form
├── about.html                  # Agency background, values, and team
├── contact.html                # Contact details and message form
├── css/
│   ├── style.css               # Main stylesheet and design system
│   ├── animations.css          # Page transitions and keyframes
│   └── responsive.css          # Mobile and tablet media queries
├── js/
│   ├── main.js                 # Mobile menu and slider controls
│   ├── calculator.js           # Trip cost estimation logic
│   └── forms.js                # Form validation and submit handling
└── README.md
```

## How to Run

Open `index.html` in any modern web browser.
